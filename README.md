# The Ledger

A private, offline personal finance app: bank accounts, credit card bill cycles, spending by category, budgets, EMIs, lending, investments with live mutual fund NAVs, a purchase planner, and an encrypted vault for notes and documents.

All data stays in the browser on the device that uses it. Nothing is sent anywhere, except NAV lookups to the public mfapi.in service.

Open the GitHub Pages site and choose **Install** (Android/desktop Chrome or Edge) or **Share → Add to Home Screen** (iPhone Safari).
